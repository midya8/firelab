# Sources, prior work and implementation boundaries

Read November10,2026. The project applies established ordinary Petri-net enabling, marking-equation and conservation theory to a deliberately small inspectable planning task. Code, controls and visual design are original; no source code or published benchmark is copied. The native runtime has no external dependency. Existing tools are much broader; no first-tool, solver superiority or speed claim is made.

## Differences not silently merged

Sources vary in invariant/semiflow naming, whether graph reductions preserve particular properties, and extensions such as timing, read arcs and inhibitor arcs. FireLab states its ordinary interleaving semantics explicitly. Shared ordinary pre/post arcs retain their enabling guards; it does not expose a separate read-arc feature. Only strict token-total conservation is accepted, a subset of general bounded or weighted-conservative nets.

The optional reference is PM4Py2.7.23, installed separately under its published license, not linked into or vendored with the MIT runtime. The installed distribution announces AGPLv3; older source-doc headers say GPLv3. We do not collapse that discrepancy into a license assurance or bundle the dependency. Native generation, independent replay and browser work without PM4Py. The reference demonstrates agreement on disclosed controls and generated inputs, not a universal equivalence proof.
